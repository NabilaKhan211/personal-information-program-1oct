# Personal Information Program

## Description
A simple Python program that accepts a user's basic information
and displays it as a clean formatted profile.

## Inputs
- Name
- Age
- City
- Email

## Concepts Used
- Variables
- input()
- Type conversion
- f-strings
- print()
